# Social Pressure Alarm

Expo + Supabase mobile app for alarms, circles, and profile sync.

## Local setup

1. Install dependencies.

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env` and fill in your Supabase project values.

3. Start a development build.

   ```bash
   npx expo start
   ```

`Sign in with Apple` is not supported in Expo Go. Use an iOS development build or `expo run:ios`.

## Supabase auth setup

The app now uses provider-based auth only:

- `Continue with Google`
- `Continue with Apple`

Before testing sign-in, configure both providers in the hosted Supabase project:

1. Go to `Authentication -> URL Configuration` and allow the app redirect URL generated by `getSocialAuthRedirectUrl()` in `lib/social/auth.ts`.
2. Go to `Authentication -> Providers -> Google` and add your Google OAuth client credentials.
3. Go to `Authentication -> Providers -> Apple` and add your Apple Services ID, team ID, key ID, and private key.
4. Make sure the Google and Apple provider dashboards both allow the same Supabase callback URL shown in the Supabase provider settings.

## Native auth notes

- The app deep-link scheme is `socialpressurealarm`.
- Google auth uses Supabase OAuth and returns through the app scheme.
- Apple auth uses native iOS authentication and exchanges the Apple identity token with Supabase.
- Apple only shares name information on the first successful authorization, so test first-run profile hydration on a fresh Apple sign-in.
